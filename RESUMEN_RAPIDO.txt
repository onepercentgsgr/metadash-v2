🎯 QUÉ ES?
─────────────────────────────────────────────────────────────────────────────────
SaaS de gestión de Meta Ads con 8 agentes IA autónomos.
Escala productos digitales automáticamente siguiendo el Playbook "Nivel Dios".

Tech: Next.js (Pages Router) + FastAPI + PostgreSQL + Claude Haiku 4.5
Deploy: Vercel (frontend) + Railway (backend + DB)

🏗️ ARQUITECTURA
─────────────────────────────────────────────────────────────────────────────────
Frontend (Vercel):
  - Landing page (marketing)
  - Dashboard (user area)
  - Playbook Nivel Dios (8 fases interactivas)
  - Admin Panel (ver/gestionar clientes)
  - Pricing (planes + MercadoPago)
  - Onboarding (5 pasos)
  - Settings (Meta token + GA4)

Backend (Railway - FastAPI):
  - Auth: JWT + bcrypt (roles: admin/client)
  - 8 agentes IA: Optimizer, Finance, Scripts, Creatives, Growth, CRO, Landing, Orchestrator
  - 3 agentes Playbook: Copywriter, Designer, Social Media
  - Endpoints: /auth/*, /config, /campaigns, /agent/*, /admin/users, /payments/*, /autonomous/
  - Scheduler: APScheduler (corre agentes cada 6 horas)
  - CORS: ManualCORSMiddleware (refleja Origin header)

Database (Railway PostgreSQL):
  - users, subscriptions, tenant_configs
  - agent_logs, autonomous_action_logs, financial_records, shopify_orders
  - Connection pooling: pool_size=10, max_overflow=20, pool_recycle=1800

📚 PLAYBOOK NIVEL DIOS
─────────────────────────────────────────────────────────────────────────────────
8 fases interactivas para escalar productos digitales en 48h (RPV > CPV):

Fase 0: Niche             → Seleccionar mercado
Fase 1: Research + Avatar → Definir target audience
Fase 2: Stack de Oferta   → Product + 3 bonuses (value > 2x price)
Fase 3: Landing Page      → Copy + design
Fase 4: Mockups + Shopify → Visual + e-commerce
Fase 5: TikTok Orgánico   → Validación pre-Meta spend
Fase 6: Meta Ads          → RPV > CPV
Fase 7: RPV vs CPV        → Análisis y scaling

Cada fase: Prompt copyable + AI button + checklist
