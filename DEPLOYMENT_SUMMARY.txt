EXAMPLE INTEGRATION:
====================

In your Flask/FastAPI endpoint:

```python
from backend.agents import run_full_audit

@app.post("/api/audit")
def run_audit(user_id: str, request_data: dict):
    # Get user's stored API key
    api_key = get_user_api_key(user_id)
    
    # Extract data
    campaigns = request_data.get("campaigns")
    creatives = request_data.get("creatives")
    finances = request_data.get("finances")
    landing_url = request_data.get("landing_url")
    
    # Run audit
    result = run_full_audit(
        campaigns_data=campaigns,
        creatives_data=creatives,
        financial_data=finances,
        landing_url=landing_url,
        negocio_info=get_user_business_info(user_id),
        api_key=api_key,
    )
    
    # Save and return
    save_audit_report(user_id, result)
    return {"report": result}
```
