═══════════════════════════════════════════════════════════════════════════
PASO 1: Abre PowerShell o CMD en tu PC
═══════════════════════════════════════════════════════════════════════════

1. Presiona Windows + R
2. Escribe: powershell
3. Presiona Enter

═══════════════════════════════════════════════════════════════════════════
PASO 2: Navega a la carpeta del proyecto
═══════════════════════════════════════════════════════════════════════════

cd C:\Users\Usuario\Downloads\metadash

(Reemplaza "Usuario" con tu nombre de usuario si es diferente)

═══════════════════════════════════════════════════════════════════════════
PASO 3: Configura Git (primera vez solo)
═══════════════════════════════════════════════════════════════════════════

git config --global user.email "gerardoreta2011@gmail.com"
git config --global user.name "Gerardo"

═══════════════════════════════════════════════════════════════════════════
PASO 4: Limpia el repositorio local (SI HAY ERRORES RAROS)
═══════════════════════════════════════════════════════════════════════════

git reset --hard origin/main
git clean -fd

(Opcional, solo si hay conflictos)

═══════════════════════════════════════════════════════════════════════════
PASO 5: Verifica el estado
═══════════════════════════════════════════════════════════════════════════

git status

Deberías ver:
- "On branch main"
- "Your branch is up to date with 'origin/main'"
- "working tree clean" O archivos modificados

═══════════════════════════════════════════════════════════════════════════
PASO 6: Agrega todos los cambios
═══════════════════════════════════════════════════════════════════════════

git add .

Verifica qué se agregó:
git status

═══════════════════════════════════════════════════════════════════════════
PASO 7: Haz el commit
═══════════════════════════════════════════════════════════════════════════

git commit -m "MetaDash SaaS v2.0 - Complete SaaS platform

- Complete FastAPI backend with JWT auth
- Next.js frontend with 10+ pages (auth, dashboard, admin, payments)
- 6 AI agents + orchestrator (Advisor, Optimizer, Creative Director, etc)
- Stripe + MercadoPago payment integration with webhooks
- Admin panel for user and subscription management
- Full SaaS features: trials, plans, tenant config, financials
- Dark theme UI, all text in Spanish
- Production-ready: Docker, Vercel config, Railway.json
- Database models: User, Subscription, TenantConfig, AgentLog, etc"

═══════════════════════════════════════════════════════════════════════════
PASO 8: Verifica el commit
═══════════════════════════════════════════════════════════════════════════

git log --oneline -3

Deberías ver tu commit nuevo arriba.

═══════════════════════════════════════════════════════════════════════════
PASO 9: PUSH a GitHub
═══════════════════════════════════════════════════════════════════════════

git push origin main

Te pedirá credenciales. Opciones:

A) HTTPS (recomendado para principiantes):
   - Nombre de usuario: onepercentsgr
   - Contraseña: Token de GitHub (ver abajo)

B) SSH (más seguro, requiere configuración previa)
   - Ya debe estar configurado

═══════════════════════════════════════════════════════════════════════════
CÓMO OBTENER TOKEN DE GITHUB (si usas HTTPS)
═══════════════════════════════════════════════════════════════════════════

1. Ve a: https://github.com/settings/tokens
2. Click en "Generate new token (classic)"
3. Dale nombre: "MetaDash Push"
4. Selecciona scopes: repo, workflow
5. Click "Generate token"
6. COPIA EL TOKEN (solo aparece una vez)
7. Úsalo como contraseña en el push

SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════

ERROR: "fatal: not a git repository"
→ Asegúrate de estar en la carpeta correcta (metadash)
→ Verifica que exista la carpeta .git (dir /a muestra carpetas ocultas)

ERROR: "Permission denied (publickey)"
→ Necesitas SSH key configurada o usar token HTTPS

ERROR: "Merge conflict"
→ Alguien más hizo cambios, haz: git pull origin main, resuelve conflictos

ERROR: "Your branch is behind"
→ Haz: git pull origin main (descarga cambios remotos)
